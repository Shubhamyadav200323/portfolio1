Cryptex

A live crypto trading platform with real market data, real order execution, and no plain-text secrets.

DocuMind

Upload a PDF, DOCX or TXT and ask it questions. Every answer cites the page it came from.

  • Retrieval pipeline using all-MiniLM-L6-v2 embeddings and cosine-similarity top-K search over document chunks.
  • Answers with citations: Llama 3.3 70B via Groq returns page and section references so users can verify each claim.
  • No request timeouts on large files: processing runs in background threads while the UI polls for live progress.
  • React drag-and-drop frontend, deployed on Vercel with the API on Railway.
